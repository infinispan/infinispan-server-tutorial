# Project Context: Infinispan Server Tutorial

A step-by-step tutorial that teaches how to use Infinispan Server with Hot Rod Java clients through a Weather monitoring system.

## Shared guidelines
- This is a learning resource — code must be clear and easy for beginners to follow.
- Prefer explicit patterns over clever abstractions. Every line should teach something.
- The tutorial has two branches: `main` (skeleton with `// STEP` placeholders) and `solution` (complete implementation). Changes must be applied to both branches.
